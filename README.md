# local ai

Консольный чат на Python. Сначала смотрит компьютер, потом спрашивает скорость, потом ум, ищет подходящий GGUF на Hugging Face и запускает его локально.

Веса, чаты и системный промпт лежат на диске. В чате модель может ходить в интернет и работать с файлами и терминалом на этом ПК — как агент, не как облачный чат.

## Что умеет

- Снимает параметры ПК: процессор, ядра, RAM, swap, видеокарту и VRAM, свободное место, режим питания, AVX2. Модель на этом шаге не выбирает.
- Спрашивает по очереди, не одной кнопкой:
  1. насколько быстро должно отвечать;
  2. насколько умным должен быть.
- Ищет по всему каталогу GGUF на Hugging Face, не по одному бренду. Отсекает vision, whisper и mmproj. Если сайт не ответил — берёт запасной вариант из локального каталога и так и пишет.
- Сам выбирает квант и контекст под свободную память. На видеокарте грузит слои в GPU, на Apple Silicon — в Metal, иначе на CPU.
- Качает модель и запускает её через `llama.cpp`.
- В чате умеет искать в интернете, открывать страницу, читать и писать файлы, создавать папки, искать по диску и запускать программы. Запись, запуск и обычные команды спрашивает. Опасные (`rm -rf` и похожие) спрашивает даже в авторежиме.
- При запуске создаёт папку `data/RAG`. Это память обучения: задание, план, вопросы и найденные страницы. В чате модель читает эти заметки. Это не дообучение весов.
- Сохраняет каждый чат. Можно продолжить, переименовать, удалить, экспортировать в Markdown.
- Системный промпт можно сменить: пресет, свой текст, только этот чат или по умолчанию. Инструкции инструментов к нему дописываются, сохранённый текст не затирают.

Запасной каталог — семейство Qwen3 (Apache 2.0), от 0.6B до 32B. Свой репозиторий с `*.gguf` тоже можно вписать, если лучший вариант не подошёл.

## Установка

Нужен Python 3.10+.

```bash
python -m venv .venv
source .venv/bin/activate          # Windows: .venv\Scripts\activate
pip install -r requirements.txt
python main.py
```

`llama-cpp-python` ставится колесом. Если колеса нет, понадобятся компилятор и cmake — это нормально, просто дольше.

### Видеокарта NVIDIA

Обычный `pip install` часто собирает только CPU. Чтобы слои пошли на GPU:

```bash
pip install llama-cpp-python --force-reinstall --no-cache-dir \
  --extra-index-url https://abetlen.github.io/llama-cpp-python/whl/cu124
```

Если колесо не подошло под твою связку CUDA:

```bash
CMAKE_ARGS="-DGGML_CUDA=on" pip install llama-cpp-python --force-reinstall --no-cache-dir
```

На Mac Metal обычно подхватывается сам. Если нет:

```bash
CMAKE_ARGS="-DGGML_METAL=on" pip install llama-cpp-python --force-reinstall --no-cache-dir
```

Приложение само скажет, если видеокарта есть, а сборка llama.cpp её не видит, и предложит вариант на процессоре.

Закрытые модели (Llama и часть Gemma) просят принять лицензию на сайте и переменную `HF_TOKEN`. Модели из встроенного каталога этого не требуют.

## Запуск

```bash
python main.py                         # железо → скорость → ум → поиск по всему Hub → чат
python main.py --scan                  # только железо, без выбора модели
python main.py --speed slow --smart max
python main.py --speed fast --smart simple --yes
python main.py --model qwen3-4b-q4
python main.py --chat 20260922-153012
```

Первый запуск показывает железо и пишет, какой размер примерно влезет. Потом два вопроса. Потом поиск и один лучший вариант, с размером и ссылкой. Перед скачиванием спрашивает — файлы бывают от ~0.5 ГБ до ~30 ГБ.

Повторный запуск предлагает прошлую модель. Ответ `n` — снова скорость, потом ум, потом поиск.

Экономия питания (`powersave` / «экономия энергии») помечается: на ней модель будет медленнее.

## Чат

```
ты › привет
ассистент › ...
  18.2 ток/с · 42 ток · 2.3 с
```

Команды:

| команда | что делает |
| --- | --- |
| `/help` | список команд |
| `/exit` | в меню, чат уже сохранён |
| `/new` | новый чат |
| `/clear` | забыть реплики, промпт оставить |
| `/prompt` | показать или сменить системный промпт |
| `/prompts` | пресеты: помощник, код, кратко, учитель, переводчик, редактор |
| `/title текст` | переименовать |
| `/history` | последние чаты |
| `/model` | какая модель и куда села |
| `/think` | показывать или прятать рассуждения |
| `/temp 0.7` | температура |
| `/tokens 1024` | лимит длины ответа |
| `/export` | markdown в `data/exports` |
| `/paste` | длинный ввод, конец — строка `EOF` |
| `/agent` | включить или выключить интернет и действия на ПК |
| `/auto` | не спрашивать обычные команды и запись. опасные всё равно спросит |
| `/cd путь` | папка, в которой агент читает, пишет и запускает команды |
| `/learn тема` | обучение: план, вопросы, потом поиск и запись в RAG |
| `/rag` | путь папки обучения и сколько занято |
| `/limits` | лимит ГБ, минуты, скорость и глубина |

Ctrl+C во время ответа обрывает генерацию. Уже написанное сохраняется.

В умном режиме Qwen3 сначала пишет блок `<think>`. По умолчанию он не мелькает в чате, в историю рассуждения всё равно пишутся. `/think` показывает их.

Если чат длиннее контекста, старые реплики выкидываются из запроса к модели. В файле история остаётся целиком.

## Где что лежит

По умолчанию папка `data/` рядом с тем местом, откуда запустили:

```
data/config.json          настройки, режим, промпт
data/chats/*.json         истории
data/models/              скачанные GGUF
data/exports/             markdown
data/RAG/                 обучение: план, источники, вложенные папки
```

Другое место: `LOCALAI_HOME=/где/угодно python main.py`. Папку моделей можно сменить в меню настроек.

В git это не попадает.

## Обучение

В меню пункт «обучение в RAG» или в чате `/learn тема`. Можно просто написать «изучи …» — программа предложит этот режим.

Порядок жёсткий:

1. Задание: что именно изучить.
2. Лимиты: сколько ГБ можно занять, сколько минут, скорость сбора и глубина.
3. Модель пишет себе план в `RAG/<тема>/plan.md`.
4. Задаёт вопросы. Пока на них не ответили, поиск не начинается.
5. Ищет только по этим ответам и запросам из плана. Страницы кладёт в `RAG/<тема>/sources/`. Папки из плана создаёт сама.

Скорость: быстро — мало страниц, медленно — больше. Глубина 1 смотрит только задание, 3 ещё и уточнения из ответов. Когда кончилось время или место, останавливается и пишет, почему.

В следующих чатах заметки из RAG подмешиваются к вопросу, если слова совпали.

## Как выбирается модель

Сначала только железо: свободная RAM, отдельная VRAM (у Apple Silicon память общая, дважды не считается), диск, питание.

Потом скорость задаёт потолок размера. «Очень быстро» не берёт модель больше комфортного потолка этого ПК. «Можно медленно» смотрит до потолка памяти.

Потом ум задаёт, откуда в этом диапазоне брать: попроще — меньший размер и Q4, максимально умный — верх диапазона и квант поплотнее. Рассуждения Qwen3 включаются, когда ум высокий, а скорость не «очень быстро».

Поиск идёт по всему каталогу GGUF на Hugging Face: несколько страниц самых скачиваемых и отдельные запросы по размеру, который влезает в этот ПК. Бренд не зафиксирован. Vision, whisper, эмбеддинги и mmproj выкидываются. Если сеть молчит, берётся запасной список и это написано прямо.

Если лучший вариант не нравится, можно взять соседний из списка, открыть каталог или вписать свой `автор/репозиторий`.

Если свободной памяти мало, потому что открыт браузер, так и напишет. Закрой лишнее и запусти снова: выбор зависит от свободной RAM, не только от установленной.

## Настройки

В меню: температура, top_p, лимит токенов, контекст, число потоков, слои на GPU (`auto` / `all` / `none` / число), показ рассуждений, папка моделей.

Контекст и GPU применяются при следующей загрузке модели.


## Если что-то пошло не так

- **Не хватает памяти, процесс умер.** Возьми режим «быстрый» или модель меньше. Контекст в настройках поставь 2048.
- **`unknown model architecture`.** Обнови пакет: `pip install -U llama-cpp-python`. Qwen3 нужна свежая сборка.
- **Качается и обрывается.** Запусти ещё раз: докачка продолжается.
- **Hugging Face не открывается.** Сначала идёт `huggingface.co`, если сеть его режет — `hf-mirror.com`. Свой адрес: `HF_ENDPOINT=https://...`. Если молчат оба, берётся запасной список, и это написано прямо.
- **Репозиторий закрыт.** Прими лицензию на его странице и задай `HF_TOKEN`.
- **На NVIDIA всё равно CPU.** Поставь GPU-сборку из раздела выше и запусти снова.
